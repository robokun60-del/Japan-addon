ここからアドオンを公開・削除できます。（サイトに戻る）

① 合言葉（トークン）

GitHub で作った「トークン」を入れてください。このスマホ・パソコンだけに保存され、ほかの人には見えません。 トークンはだれにも教えないでください。

② アドオンを公開する

③ 公開中のアドオン

  • トークンを保存すると表示されます

トークンの作り方（最初の1回だけ）

  1. トークン作成ページを開く
  2. 「Token name」に addon-site など好きな名前を入れる
  3. 「Expiration」で期限を選ぶ（1年など）
  4. 「Repository access」で Only select repositories を選び、Japan-addon を選ぶ
  5. 「Permissions」の「Repository permissions」→ Contents を Read and write にする
  6. いちばん下の「Generate token」を押し、出てきた github_pat_ で始まる文字をコピーして、上の①に貼る

トークンが他の人に知られたら、GitHub の同じページで「Delete」して作り直してください。
